# SADE Reproducibility
This branch is for reproducing manuscript result

All scripts for reproducing analysis results are within the `EDA` folder.   
It is for historical reasons the analysis scripts folder is named as `EDA`.     


## System Requirements
[samtools](https://www.htslib.org)
needs to be callable in your OS.   
[bamCoverage](https://deeptools.readthedocs.io/en/develop/content/tools/bamCoverage.html)
needs to be installed in your python environment.   
[Genrich](https://github.com/jsh58/genrich)
needs to be callable in your OS.    
[bedtools](https://bedtools.readthedocs.io/en/stable/)
needs to be callable in your OS.    
[Homer](http://homer.ucsd.edu/homer/ngs/annotation.html)
needs to be callable in your OS.

We suggest 
  you copy and paste the whole subfolder `EDA` to outside of the local-sade-path,   
  make suitable and necessary changes to the file paths within those scripts,   
  and execute the scripts based on the instructions within,   
  all the while keeping the local-sade-path at main branch.
